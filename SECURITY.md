# Security policy

## Reporting a vulnerability

Report security issues privately through GitHub's private vulnerability reporting: open the repository's **Security** tab and select **Report a vulnerability**, or go to <https://github.com/dev1f965x/kindly-bartender/security/advisories/new>.

Do not open a public issue for a security problem. Include the affected feature or file, steps to reproduce, and the impact you expect.

kindly-bartender is maintained by one person, so reports are handled on a best-effort basis. You will get a reply in the advisory once the report has been reviewed.

## Supported versions

Fixes go to the `main` branch.

## Security checks

GitHub secret scanning with push protection and Dependabot alerts are enabled for the repository. Renovate opens dependency update pull requests.

## Accepted advisories

None.
